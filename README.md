# 🎓 Placement Management System

A simple and colorful web-based Placement Management System built using HTML, CSS, and JavaScript.

## 📌 Project Overview

This project helps colleges manage student placement information easily.
It provides a dashboard to manage students, companies, and placement records.

## ✨ Features

- 📊 Dashboard with placement statistics
- 👨‍🎓 Add, Edit, Delete and Search Students
- 🏢 Add, Edit, Delete and Search Companies
- 💼 Add, Edit, Delete and Search Placements
- 📈 Placement Efficiency Dashboard
- 💾 Data stored using Browser LocalStorage
- 📱 Responsive and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
